# Agent 编写规范

> **按需加载**：本文件只在**读取 `agents/` 或 `.claude/agents/` 下文件时**进入上下文（改 Agent 前必先读该 Agent 文件，故必然触发）。
> 它不影响任务闸门与路由——那两类规则保持常驻。

所有 Agent `.md` 文件遵循统一格式，确保 orchestrator 可解析、可路由。

## 文件模板

```markdown
# Agent 名称

> 一句话描述定位

## 职责
- 职责 1
- 职责 2

## 输入
| 参数 | 类型 | 说明 |
|------|------|------|
| 参数名 | string/... | 说明 |

## 输出
- 输出 1
- 输出 2

## 可用工具
- 技能 / MCP / CLI

## 调用方式
被谁调用、在什么场景下调用

## 约束
- 行为限制
- 输出规范
```

## 基本原则
- **独立**：每个 Agent 不依赖其他 Agent 的内部状态
- **声明式接口**：输入/输出清晰，orchestrator 据此编排
- **沙箱意识**：文件读写局限在 `research-assistant/` 内
- **技能复用**：优先调用本仓库 `.claude/skills/` 中的专业技能（17 个，2026-09-20 由父层迁入）

## 引用与单一源约定

规则文件与 Agent 文件在任务开始时**都会被加载**，所以指针省下的不是一次读取，而是**一个维护点**。
但指针会让人多跳一次文件，故必须配一条硬约束：**每个 Agent 文件执行时，除自身输入产物外，
额外打开的文件数 ≤ 2**（跳转按**文件**计，6 条指针指向同一文件仍只算 1 次）。

### 1. 路径写法（唯一约定）

工具按 **CWD（= 仓库根）** 解析相对路径，因此「相对本文件所在目录」的写法必然被解析错。
只允许以下三种写法：

| 目标 | 写法 | 示例 |
|------|------|------|
| 沙箱内 | **仓库根相对**，不带 `./`，**禁止上行相对路径** | `knowledge/mcm/templates/node-checklists.md` |
| 沙箱外（用户级 / 外部目录） | **不写路径**，只写逻辑名 | 用户级 `~/.claude/skills/` 中的某个技能；`additionalDirectories` 中的外部目录 |
| "相对某目录"的短名表 | **表头必须显式声明基准** | 表头写「（`agents/` 相对）」 |

沙箱外不给路径另有一层考虑：用户级与外部目录不在本仓库的版本控制与规则体系内，写死路径会在其
结构调整时**静默失效**——无报错、无告警。故沙箱外内容一律按逻辑名引用。
（2026-09-20 两层合并：父层规则并入本仓库，父层 17 个技能迁入本仓库 `.claude/skills/`。
父目录现仅剩 `settings*.json` 与一个指针 `CLAUDE.md`，已不是项目的组成部分。）

### 2. inline 还是指针（三问法）

| # | 问题 | 裁定 |
|---|------|------|
| Q1 | 归属：跨文件复用的**定义**，还是本 Agent 的**用法**？ | **用法 → 一律 inline**，不论轻重（如主控对下属 Agent 的调用口径） |
| Q2 | 形态：≤2 行且无表格？ | 是 = 轻 |
| Q3 | 保真：执行者是否必须**逐字照抄**列名/枚举值/编号？ | 是 → 见下 |
| — | Q1=定义 且 Q3=要照抄 | inline，但**只允许存在于生产者/唯一源那一处**，其余全部改为指针 |
| — | Q1=定义 且 Q3=不要 且 重 | **必须指针** |

**关键推论**：契约类内容的唯一源是它的**生产者**，不一定是规则文件。
（例：答案速查表的表头源在 `agents/mcm/writer-agent.md`，因为它才是产出者；
规则文件与模板反而改为指针。这样执行者不必跳转，跳转成本落在只核验一次的 critic/N7 上。）

### 3. 硬禁

- **抽样式复述一律删**：凡由「如 / 等 / 例如」引出的列举，都是漂移源。要保留就写全，写不全就改指针。
- **禁止为同一实体维护两个计数器或两份表头**。同一循环的两个说法必须合并为一个口径，
  否则会被读成可以叠加。

### 4. 镜像例外

唯一源在沙箱外、且磁盘上存在多份物理副本时，允许且仅允许**一处本地镜像**，
并须标注「镜像自 X，以 X 为准」，其余引用指向该镜像。

**现存唯一实例：`math-modeling-writing`。** 用户级 `~/.claude/skills/`（A）与本仓库
`.claude/skills/`（B）各一份，内容仅差编译产物。2026-09-17 实测从本工作目录调用 Skill 解析到 **A**；
2026-09-20 技能迁入本仓库后 B 成为标准的项目级位置，**解析可能翻转为 B**。
无论翻不翻转，改内容时仍须 **A、B 两份都改并比对 md5**——只改一份会在另一条解析路径下静默失效。
