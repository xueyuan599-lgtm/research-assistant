# MCM Track — 数学建模国赛赛道（常驻薄壳）

> 全国大学生数学建模竞赛（CUMCM）自动化流水线。输入赛题，输出论文+代码+结果。
> **逐环节协作**：不一次性输出全文，每环节 **plan → auto → 完成+自检 → 停止**，汇报后等用户指令再做下一环节。
> **评审得分导向**——每环节产出对齐评委最终能看到的东西（摘要、答案、图表、规范）。
>
> **本文件只承载路由与硬约束**。流程细节、环节清单、Agent 分工、强制规则详解见
> `.claude/rules/04-mcm-track-detail.md`——**凡涉及具体环节执行，先读该文件**。

## 触发条件

以下任一条件满足即识别为 MCM 赛道：

| 触发信号 | 示例 |
|---------|------|
| 关键词 "数学建模" / "国赛" / "CUMCM" / "数模竞赛" | "帮我做数学建模国赛C题" |
| 关键词 "美赛" / "MCM" / "ICM" | "美赛2025B题" |
| 关键词 "建模赛题" / 明确赛题编号 | "CUMCM 2024 Problem C" |

## 协作模式（强制）

```
总规划（一次性：选题 → 审题拆解+全局方案 → 数据审查）
  → 环节循环（逐环节：plan → auto → 完成+自检 → 停止，等指令）
  → 终稿合并（一次性：合并 → critic 评审自查 → 交付）
```

**逐环节停止是硬约束**：每环节完成后主控汇报并**暂停等用户指令**，不擅自连跑后续环节。
用户显式说"连跑 N 个环节"时除外。用户可随时插话指定环节（part_scope 优先生效）。

产出约定：每节一个独立文件 `paper/sections/{序号}-{章节}.md`，编号衔接已有草稿。

## 真决策点（需实质裁决，与常规停点相区分）

| 节点 | 内容 |
|------|------|
| **N0** | 选题确认（题目已定可跳过） |
| **N2** | 模型路线 + 环节清单确认 |
| **N7** | 论文终稿确认 |

常规环节停点用户回一句"继续"即可；以上三点需团队**实质裁决**。

## 硬约束

| 约束 | 内容 |
|------|------|
| **篇幅** | 正文自第四页起，**不超过 30 页**，**不要目录**；附录在正文之后，**页数不限**。依据《全国大学生数学建模竞赛论文格式规范》(2026) 第三、四条，原文见 `knowledge/mcm/templates/format2026.txt` |
| **答案** | 每小问必须输出与题型匹配的**明确可定位**最终答案（优化题：最优方案+目标值；预测题：预测值+误差区间；评价题：排序/分级+权重；机理题：解析表达/规律/阈值），可在 30 秒内定位 |
| **禁止模型堆砌** | 新增模型必须说明解决了基础模型的何种**具体困难**；至少设一个基础基准模型 |
| **禁止伪造创新** | 不得将常规模型、预处理或常规可视化表述为创新 |
| **数据** | 以实际附件为**唯一依据**，不得编造字段/样本/数值；必须检测数据泄漏 |
| **代码** | 必须**实际运行验证**（前提条款见 `.claude/rules/06-cost-discipline.md` §一），未运行内容标 `[待运行]`；固定随机种子 |
| **写作** | 正式中文；流程图用 Mermaid；符号首次出现必须定义；每结论须有真实数据/公式/表格/图形支撑；参考文献按 GB/T 7714 逐条核验；遵守 `.claude/rules/02-academic-writing-standards.md` 禁用词表 |
| **成本** | 检验分层（L1/L2/L3）、产出纪律、审查轮次封顶 ≤3 —— 唯一源在 `.claude/rules/06-cost-discipline.md`，本文件不复述 |
| **作用域** | 所有输出限于 `research-assistant/` 内（`.claude/rules/00-scope-boundary.md`） |
