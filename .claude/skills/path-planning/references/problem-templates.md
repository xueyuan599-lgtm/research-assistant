# 路径规划问题模板

> 常见路径规划问题的数学建模模板，标注了每个模型的不可行风险点和对应的修复策略。

---

## 1. TSP（Traveling Salesman Problem）

### MTZ 形式（Miller-Tucker-Zemlin）

**变量**：
- `x[i,j] ∈ {0,1}`：是否从 i 到 j
- `u[i] ∈ R`：城市 i 在路径中的访问次序（辅助变量消除子环）

**目标**：
```
min  sum_i sum_j d[i,j] * x[i,j]
```

**约束**：
```
每个城市恰出一次:   sum_j x[i,j] = 1, ∀i
每个城市恰入一次:   sum_i x[i,j] = 1, ∀j
子环消除 (MTZ):     u[i] - u[j] + N * x[i,j] <= N - 1, ∀i≠j, i,j > 0
变量界:             1 <= u[i] <= N - 1, ∀i > 0
```

**⚠️ 不可行风险**：
| 风险 | 原因 | 修复 |
|------|------|------|
| 子环约束过紧 | u[i] 界不够宽（需 N 而非 N-1） | 检查 x[i,i] 是否被禁止，u 的界 |
| Big-M 过小 | N 城市数时，MTZ 的 M = N 在 u[i]=N-1 时失效 | 确保 M = N 且 u ∈ [1, N-1] |
| 对角线未禁止 | x[i,i] 可能被选 | 加约束 x[i,i] = 0 |

### DFJ 形式（Dantzig-Fulkerson-Johnson）

**变量**：同 MTZ（但无需 u[i]）

**约束**：
```
每个城市度数为 2:   sum_j x[i,j] + sum_j x[j,i] = 2, ∀i      （无向图版本）
子环消除 (DFJ):     sum_{i∈S} sum_{j∈S} x[i,j] <= |S| - 1, ∀S⊂V, 2<=|S|<=N-2
```

**⚠️ 不可行风险**：
| 风险 | 原因 | 修复 |
|------|------|------|
| 子环约束指数多 | 需要 lazy constraint callback 动态添加 | 使用 callback（Gurobi: `cbLazy`） |
| 疏漏子环 | 初始未加任何子环约束，得到非法子环 | 求解后检查解，有子环则加约束重新求解 |

### TSP 修复策略
1. **诊断**：检查解中是否有多个子环
2. **松弛**：将 MTZ 换成 DFJ + lazy constraints（更鲁棒）
3. **修复**：先用最近邻法生成初始解做 warm-start

## 2. CVRP（Capacitated Vehicle Routing Problem）

### 两指标形式

**变量**：
- `x[i,j,k] ∈ {0,1}`：车辆 k 是否从 i 到 j
- `u[i,k] ∈ R+`：车辆 k 到达 i 时的累积载重

**约束**：
```
每个客户被服务一次:  sum_k sum_j x[i,j,k] = 1, ∀i > 0
车辆从车场出发并返回: sum_j x[0,j,k] = sum_i x[i,0,k] = 1, ∀k
容量约束:            u[i,k] = u[j,k] + demand[i] 如果 x[i,j,k] = 1
                   demand[i] <= u[i,k] <= capacity[k], ∀i, k
```

### 三指标形式（更紧凑但变量更多）

**变量**：
- `x[i,j] ∈ {0,1}`：是否有车辆从 i 到 j（不区分车辆）
- `f[i,j] ∈ R+`：经过边 (i,j) 的累积载重（流变量，用于容量约束）

**约束**：
```
流守恒（容量隐含）: sum_j f[i,j] - sum_j f[j,i] = demand[i], ∀i
                 0 <= f[i,j] <= capacity * x[i,j], ∀i,j
```

**⚠️ 不可行风险**：
| 风险 | 原因 | 修复 |
|------|------|------|
| 总需求 > 总容量 | `sum demand > K * capacity` | 增加车辆或使用软容量约束 |
| 单车容量不足以服务单个客户 | `max demand > capacity` | 检查最大需求是否超限 |
| 路径断裂 | 流变量 f[i,j] 不连续 | 检查流守恒约束的正确性 |

### 修复策略
1. **诊断**：检查 `sum demand_i <= K * capacity` 是否满足
2. **松弛**：容量约束加松弛变量 `- s_i`
3. **构造**：用 Savings 算法生成初始可行路径
4. **验证**：检查每条路径上的累积需求

## 3. VRPTW（VRP with Time Windows）

### 时间窗约束

**额外变量**：
- `t[i] ∈ [a_i, b_i]`：到达客户 i 的时间

**约束**：
```
到达时间递推:     t[i] + s[i] + travel[i,j] <= t[j] + M * (1 - x[i,j]), ∀i,j
时间窗约束:       a[i] <= t[i] <= b[i], ∀i
其中 s[i] = 服务时间
```

**⚠️ 不可行风险**：
| 风险 | 原因 | 修复 |
|------|------|------|
| 时间窗不可调和 | 客户间距离 + 服务时间 > 时间窗间距 | 软时间窗（加惩罚） |
| Big-M 过小 | M 应 >= max(b) - min(a) + max(travel) | 取大值如 1e5 |
| 空驶路径 | 车辆从车场出发到第一个客户的时间不足 | 调整时间窗或增加车辆 |

### 修复策略
1. **松弛**：时间窗约束 + 松弛变量（设惩罚系数）
   ```
   t[i] <= b[i] + s_pos[i]       # 延迟到达
   t[i] >= a[i] - s_neg[i]       # 提前到达
   ```
2. **构造**：Regret-insertion 启发式，优先插入时间窗最紧的客户
3. **LNS**：移除时间窗冲突最多的客户，重新插入

## 4. Job Shop Scheduling

### 析取形式（Disjunctive Formulation）

**变量**：
- `s[i] ∈ R+`：工件 i 的开始时间
- `y[i,j] ∈ {0,1}`：工件 i 是否先于 j 在同一机器上加工

**约束**：
```
加工顺序:           s[j] >= s[i] + p[i] - M * y[i,j], ∀i,j 同机器
                    s[i] >= s[j] + p[j] - M * (1 - y[i,j]), ∀i,j 同机器
工序前置关系:        s[j] >= s[i] + p[i], ∀i -> j 工序
时间窗:              r[i] <= s[i] <= d[i] - p[i]  （最早开始/截止时间）
```

**⚠️ 不可行风险**：
| 风险 | 原因 | 修复 |
|------|------|------|
| 截止时间过紧 | 总加工时间 > 可用时间 | 松弛截止时间（软约束） |
| 资源冲突 | 同一机器上两个工件时间重叠 | 检查析取约束的 Big-M |
| 前置关系矛盾 | 循环依赖 | 检查工序 DAG 是否有环 |

### 修复策略
1. **诊断**：计算总加工时间的理论下界 `max_machine sum(p[i])`
2. **松弛**：截止时间约束做软约束
3. **构造**：最短加工时间优先（SPT）调度

## 5. 分配问题（Assignment Problem）

### 经典形式

**变量**：
- `x[i,j] ∈ {0,1}`：将任务 j 分配给 worker i

**约束**：
```
每个任务一人:     sum_i x[i,j] = 1, ∀j
每人至多一任务:   sum_j x[i,j] <= 1, ∀i
```

**⚠️ 不可行风险**：
| 风险 | 原因 | 修复 |
|------|------|------|
| 任务数 > 人数 | 不可能一人多任务 | 改为每人可多任务或增加虚拟人 |
| 不兼容对 | 某些 (i,j) 组合不可行 | 加 `x[i,j] = 0` 显式约束 |
| 成本矩阵不对称 | 无心的 NaN/Inf | 数据清洗 |

### 修复策略
1. **诊断**：检查人数与任务数的比例
2. **松弛**：将 `=1` 换为 `>=1` 和 `<=1`，或增加虚拟变量
3. **修复**：多余任务用虚高成本分配给虚拟人

## 通用诊断清单（每次建模后自查）

### 规模一致性
- [ ] 变量索引范围：每个下标是否对应正确的集合？
- [ ] 数据矩阵尺寸：距离/成本矩阵是 N×N 吗？（不是 (N-1)×N？）

### 约束完整性
- [ ] TSP：子环约束是否添加？（MTZ 或 DFJ）
- [ ] VRP：每辆车都从车场出/回车场了吗？
- [ ] 时间窗：a[i] <= b[i] 对所有 i 成立吗？
- [ ] 容量：没有单个需求超过最大容量？

### 数据合理性
- [ ] 距离矩阵对称吗？（对称 TSP 才对称，非对称 TSP 不要求）
- [ ] 三角不等式成立吗？（如果不成立，某些算法会有问题）
- [ ] 所有需求/距离/时间都是正数吗？

### 求解器准备
- [ ] 模型文件已保存（`model.lp` / `model.mps`）？
- [ ] 如果 INFEASIBLE → 我已知道怎么提取 IIS
- [ ] 小规模实例（N=5-10）先跑通了吗？
