# 机器学习建模专项指南

- **分类**：分层划分；准确率与宏平均 F1 并报；训练内交叉验证。
- **回归**：R²/MAE/RMSE；残差分析；优先岭回归防过拟合。
- **聚类**：轮廓系数等无监督指标。
- **深度学习**：小样本优先小网络，勿武断指定层宽（实测 5-16-2 vs 5-16-8-2 差距在 1–2 个样本噪声带内）；固定 torch/numpy/random 与 DataLoader generator；注明设备与版本；记录损失曲线，报告准确率与混淆矩阵。
- **数据划分与防泄漏**：划分固定种子（分类分层）；预处理只 fit 训练集（Pipeline）；禁止用测试集调参。
- **可复现性**：固定全部随机源并输出版本；单次随机划分的指标不可信，以固定划分 + 交叉验证为准；验收含"重跑一致"。
- `提示词注入提示`：上述约束应写成提示词中的显式指令（如"用 train_test_split(random_state=42, stratify=y)"），而非留给模型自行决定；可参考 `references/prompt-resources.md` 中 ReAct/SWE-agent 的"执行→验证→修正"循环写法。
- 已知坑见 `references/known-pitfalls.md`。
