# 提示词工程效果评估与对比评测协议

用于：① 优化交付前自检与用户审阅；② 同一题面 × 多组提示词的对比评测。

## 评估维度（6 项）

| 维度 | 说明 |
|---|---|
| 可运行性 | 是否一次跑通；修复轮次 |
| 结果正确性 | 与冻结基准对比（最优解偏差、误差指标、准确率） |
| 指标完整性 | 任务要求指标是否齐全（MAE/MAPE、R²/MAE/RMSE、acc+宏F1、灵敏度） |
| 结构完整度 | 建模：模型/假设/符号/灵敏度或评估/结论；ML：划分/预处理/评估/可视化/结论 |
| 可复现性 | 固定种子、依赖版本、数据路径；重跑一致 |
| 主观质量（1–5） | 可读性、代码、图表、结论 |

## 审阅清单（交付前自检与用户审阅共用）

- 角色/背景/步骤/格式/约束/验收是否齐全？验收是否含指标 + 种子 + 重跑一致？
- 方法与工具是否有来源（检索或实测）？已知坑/防泄漏是否注明？是否虚构数据？
- **资源溯源**：优化稿中声称的先进方法/最佳实践是否能在资源检索记录中找到对应条目？无出处的建议必须标注为"基于通用知识"？若声称来自论文/仓库但检索记录无对应，视为未验证，须补检或删除。
- 用户审阅重点：原始意图是否保留？新增内容是否合理？有无范围扩张？默认取舍是否认可？

## 对比评测协议

1. 固定同一题面、数据（记录校验和）与环境；
2. 冻结基准（固定脚本预计算参考解）；
3. 各组隔离执行，提示词为唯一输入，允许自主修复；
4. 记录首次运行、修复轮次、结果与产物；每组重跑一次验证可复现；
5. 按 6 维度打分，输出对比表与结论。
