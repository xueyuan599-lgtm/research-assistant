# 已知坑速查卡（优化前先查，命中可跳过对应搜索）

| 领域 | 已知坑 | 正确做法 |
|---|---|---|
| 优化 | linprog 默认求最小化、不支持整数变量 | 最大化对目标取负；整数规划用 PuLP |
| 预测 | 小样本高阶季节 SARIMA 易不收敛 | 优先 Holt-Winters（ExponentialSmoothing, m=12）或低阶 SARIMA，附朴素基线 |
| 预测 | 数据含趋势转折/结构变化时模型滞后、多模型分歧 | 用滚动起点回测；明示滞后，输出区间/分歧说明 |
| 评价 | 熵权法要求正向化后数据非负 | 成本型取倒数或 max-x 正向化；校验权重和为 1 |
| 分类 | 类别不均衡时只看准确率会误导 | 同时报宏平均 F1；分层划分 + 交叉验证 |
| 回归 | 小样本线性回归易过拟合 | 优先岭回归；报 R²/MAE/RMSE，做残差分析 |
| 深度学习 | 单次随机划分的 acc 不可信 | 固定划分 + 多种子重复；跨配置同划分比较 |
| 可复现 | 无种子→重跑指标漂移 | 固定全部随机源（含 torch/DataLoader generator），输出版本与设备 |
