# 图表引用与排版规范

## Word 样式架构（关键）

- 标题、图表注、正文必须使用相互独立的 Word 样式，禁止在正文样式上手动叠加格式，避免格式错乱。
- 一级标题编号约束：一级标题必须带中文数字编号，按“一、二、三……”顺序排列（如“一、问题重述”“二、模型假设”）；题目、摘要标题、参考文献与附录不加编号。源稿标题可带可不带编号，Word 转换时自动补齐且不重复添加。
- 独立样式清单：题目、摘要标题、摘要正文、正文、一级标题、二级标题、三级标题、图注、表注、表格文字。
- 每个自定义样式：样式类型为段落，样式基准为无样式，后续段落样式为正文；需要修改格式时在“修改样式”中统一更新。
- 全文行距统一为 1.5 倍。

## 图

- 编号：按正文出现顺序编号，图 1、图 2……；标题格式统一为“图 1：标题”（图与编号间空格，编号后接冒号）。
- 图注位置：位于图的下方，使用独立“图注”样式。
- 正文引用：每个图在正文中至少被引用一次，引用先于图出现；引用句式用“如图X所示”“由图X可以看出”“图X给出了”“（见图X）”。
- 引用后解读：引用之后必须对图内容作解读，说明从图中得到什么结论，不留无引用的孤立图。
- 占位图：尚未插入图片时，也用“如图X所示”写出引用句，并保留【图占位：……】标记。

## 表

- 编号：按正文出现顺序编号，表 1、表 2……；标题格式统一为“表 1：标题”（表与编号间空格，编号后接冒号）。
- 表注位置：位于表的上方，使用独立“表注”样式。
- 正文引用：每个表在正文中至少被引用一次，引用先于表出现；引用句式用“如表X所示”“表X给出了”。
- 三线表：顶线与底线 1.5 磅、表头下线 1.0 磅；数字不带单位，单位归并在栏目中；表格文字使用独立“表格文字”样式（五号，基于无样式，不缩进，行距 1.5 倍，居中）。
- 表格整体水平居中，宽度不超过页边距。
- 防溢出：超长数字串、英文单词、URL 等需允许断行，防止溢出单元格；表头过长时缩写或换行。
- 防留白：简单表收缩到内容宽度，避免列被拉宽产生大量留白；复杂长文本表使用可换行的列，必要时在五号至六号之间调小字号。

## 公式

- 公式居中排版，编号位于右侧，编号按出现顺序为式 (1)、式 (2)……。
- 公式布局约束：Word 中公式主体必须围绕“居中制表位”居中，编号必须由“右制表位”推到右侧；公式段落结构固定为“制表符 + 公式 + 制表符 + 编号”，禁止使用仅整行居中的写法，否则公式会偏左、编号与公式粘在一起。
- Markdown 源稿一律使用 `$$...\tag{N}$$`，编号从 1 连续；正文首次出现公式时解释其中的符号，不依赖符号表。
- 转换与校验必须满足：公式为 Word 原生 OMML、数量与源稿一致、编号连续、两制表位布局完整（居中制表位、右制表位、公式前制表符三者缺一即视为不通过）。

## 引用顺序总则

先见文、后见图表：正文引用句在前，图表在后；每个图表至少被引用一次并配解读。

## LaTeX 备注

- 行距 1.5 倍：`\usepackage{setspace}` 配合 `\setstretch{1.5}`。
- 表格与列举项规范见 `guoshi-writing-guide.md` 第四节：简单表用 tabular 全居中，复杂表用 tabularx，浮动用 [!htbp]，表头居中加粗，enumerate 自动编号；表格字号优先 \footnotesize 或 \small，长内容放 X 列并加 \raggedright 防溢出。
