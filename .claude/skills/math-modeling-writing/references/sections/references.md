# 参考文献章节模块

## 功能

整理正文引用的文献，按 GB/T 7714-2015 顺序编码制编号；正文引用处标注 [1]、[2] 等。

## 输入依赖

- 正文中实际引用的文献清单（作者、题名、出处、年份、页码）
- 正文引用位置标注

## 输出骨架

```markdown
# 参考文献

[1] 作者. 题名[文献类型标识]. 出版地: 出版社, 出版年.
[2] 作者. 题名[J]. 刊名, 年, 卷(期): 页码.
……
```

## 写作规则

- 引用别人的成果必须在原文明确标注，引用格式正确（国赛指南要求）。
- 顺序编码制：按正文首次出现顺序编号，正文用 [n] 标注。
- 格式按 GB/T 7714-2015：专著 [M]、期刊 [J]、学位论文 [D]、会议 [C]、网络 [EB/OL] 等。
- 只列正文实际引用的文献，不列装饰性文献。
- 中英文文献统一格式；作者超过三人用“等”。

## 常见句式

- “文献[1]指出……”。
- “……见文献[2]”。

## 自检清单（强制最后一步）

1. 格式统一：全部条目符合 GB/T 7714-2015。
2. 编号顺序与正文出现顺序一致。
3. 正文所有引用均有对应条目，条目均被正文引用。
4. 文献类型标识正确。
5. 无多余小括号（[n] 为引用标注，不属正文小括号）。
6. 反 AI。
