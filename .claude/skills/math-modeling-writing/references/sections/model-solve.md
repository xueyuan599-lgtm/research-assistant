# 模型建立与求解模块（逐问一级标题 + 定制化三级标题）

## 功能

按 C023 格式组织：每个问题对应一个一级标题，内部按该问的具体建模内容定制二级与三级标题。多问论文中每个问题遵循同一组织原则，但各级标题随问题内容不同而定制，不使用空泛通用标题。

## 输入依赖

- 各问的模型表达式、决策变量、约束条件（来自建模过程与代码）
- 运行结果与中间结果（日志/CSV/JSON/图）
- 符号命名（衔接符号说明模块）

## 输出骨架（组织原则，标题按问题定制）

```markdown
# 四、问题一：<模型主题>

[嵌入分析 1~2 段：核心目标 → 要点与难点 → 建模思路]

[图占位：图 X 问题一流程图]

## 4.1 <按问题定制的二级标题>
### 4.1.1 <按问题定制的三级标题>
……
## 4.2 <按问题定制的二级标题>
……
## 4.N 结果
……
## 4.N+1 稳健性分析（可选）
收敛稳定性、参数灵敏度、可靠性评估……
## 4.N+2 结论
一两句总结本问的模型、方法与关键结果；可选编号要点列出主要发现
```

二级标题按该问阶段按需取舍，常用阶段：问题X模型的建立与求解、数据预处理、模型建立、模型求解、模型检验、结果分析。

## 三级标题定制化范例（来自五篇语料）

- 数据类：数据预处理；描述性统计与可视化；响应变量与自变量处理。
- 模型类：折射率模型建立；模型结构；决策变量与目标函数；约束条件。
- 求解类：模型求解；参数估计；厚度反演算法。
- 检验类：模型检验；随机效应必要性检验；残差分析；灵敏度与可靠性评估。
- 结果类：结果分析与对比。

## 写作规则

- 每个问题一个一级标题，编号连续；子节编号随标题号递增。
- 二级标题按阶段取舍，三级标题必须定制化：每个三级标题能体现该问的具体内容，禁止“模型建立 / 模型求解 / 结果”式空泛三级标题堆叠。
- 建模与求解截然分开；必须有明确的模型表达式，公式编号占位。
- 求解为算法式分步步骤，不能以程序代替求解过程。
- 求解节除步骤描述外，应给出关键公式或判定式（如编码定义、算子规则、约束检查式），并为算法流程图、编码示意图等预留位置。
- 公式中的符号在正文首次出现处解释，不依赖符号表。
- 每个图/表在正文中至少被引用一次，引用先于图/表出现（如图X所示、见表X），引用后必须解读；占位图也要写引用句。图注在下方、表注在上方，详见 `references/typography.md`。
- 结果要全：所有问题都要有详细结果和中间结果；结果放在对应位置，尽量不放附录。
- 每问在结果之后加一小段结论：先用一两句总结本问建立的模型、采用的方法与关键结果，再视需要用编号要点列出主要发现；二级标题用“结论”（参考 C023 的 4.5 结论写法）。
- 灵敏度分析、稳健性、鲁棒性、可靠性评估属于模型建立与求解的各问内部，作为该问可选二级/三级标题（如 4.N 稳健性分析、4.N.1 参数灵敏度分析），不写入文末模型评价章。
- 分析嵌入开头且不重复；符号命名规范；无多余小括号；反 AI。

## 常见句式

- 嵌入分析：“问题一的核心目标是……。”
- 模型建立：“设决策变量……，优化目标为……”“本节采用……模型”。
- 求解：“求解步骤如下：Step1……Step2……”。
- 结果：“三种方案的对比结果如表 X 所示”“由图 X 可见……”。

## 自检清单（强制最后一步）

> 6 项，按得分相关性选取。纯文风项（三级标题定制化、模板复用、无多余小括号等）已删除——
> 它们不影响评委判断，但每问都要过一遍，成本全落在写作环节。

1. **结构与求解**：建模与求解分开；有明确模型表达式并带公式编号；求解为算法式分步，不以程序代码替代。
2. **符号**：公式中符号在正文首次出现处已解释，全文同一字母体系。
3. **图表引用**：每个图/表在正文有引用，先引用后出现，引用后有解读；占位图也带引用句。
4. **结果齐全**：中间结果与最终结果都在，且图表引用放在对应位置（尽量不放附录）。
5. **每问结论段**：标题为“结论”，总结模型、方法与关键结果；灵敏度/稳健性等检验内容放在本问内部，不写入模型评价章。
6. **可回溯 + 反 AI**：论文内每个数值能回溯到 `outputs/` 的具体字段；无 AI 套话与禁用词。
