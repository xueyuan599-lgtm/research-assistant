# 模型假设章节模块

## 功能

把建模前提系统化：明确哪些条件由题目给定、哪些做了简化、哪些来自模型自身，用严格确切的语言列出，保证后续模型推导与结果解释有据可依。

## 输入依赖

- 题目明确给定的条件与数值（阈值、时长、窗口、参数取值等）
- 模型选择与求解思路（来自问题分析）
- 数据特征（是否存在误差、重复测量、噪声等）

## 输出骨架

```markdown
# 模型假设

为简化问题，本文做出以下假设（可按主题分组）：

- 假设1：假设陈述。理由/说明用叙述句表达。
- 假设2：假设陈述。理由/说明用叙述句表达。
- ……

以上假设分别支撑……的计算/推导。
```

## 写作规则

- 按来源优先级组织（国赛指南）：题目明确给出 → 排除小概率事件 → 只考虑核心因素 → 模型自带假设 → 参数形式假设 → 简化模型的假设；逐条可标注来源类别。
- 每条 = 严格陈述 + 理由；格式“假设X：……”，直接写陈述，不带主题标签。
- 语言严格确切：用“假设……不随……变化”“服从……分布”“忽略……对……的影响”等确定句式，不用“大概、可能、尽量”等模糊词。
- 正文不使用非必要小括号：来源与理由用叙述句表达（如“按题目规定”“考虑到……”），不用“（来源：……）”式标注；缩写括号仅在术语首次出现时使用一次。
- 与结果有因果关系：每条假设都应被后文模型或结果解释使用，不写孤立假设。
- 数量 3~5 条；可按主题分组（如数据假设、物理特性假设、分布假设、约束假设）。
- 数值型假设（阈值、参数、窗口）必须来自题目或数据，禁止编造。
- 反 AI：无括号堆叠、无概念堆叠、无营销化措辞。

## 常见句式

- 引入：“为简化问题，本文做出以下假设：”
- 题目给定：“题目给定……，因此本文假设……”。
- 简化：“忽略……对……的影响”“假设……为常数”。
- 模型自带：“假设……服从均值为零的正态分布”“假设……相互独立”。
- 理由：“为简化模型的同时贴合现实情况……”。

## 自检清单（强制最后一步）

1. 来源完整：每条假设能对应“题目给定/简化/排除小概率/模型自带/参数形式”之一。
2. 语言严格：无“大概、可能、尽量”等模糊词。
3. 因果关联：每条假设在后文模型或结果解释中被使用。
4. 数量适中：3~5 条，不堆砌。
5. 无虚构：数值型假设有出处（题目或数据）。
6. 分组清晰：多类假设按主题分组（可选）。
7. 反 AI：无括号堆叠、无概念堆叠、无营销化措辞。
8. 无多余小括号：正文无“（来源：…）”等非必要括号。
