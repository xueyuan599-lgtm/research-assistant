# 符号说明章节模块

## 功能

从模型表达式中提取主要符号，生成“符号 / 含义 / 单位”三线表；符号书写遵循 IEEE Editorial Style Manual 与 ISO 80000-2 / GB 3102.11 规范；不使用程序变量名。

## 输入依赖

- 模型表达式与约束条件（来自模型建立与求解）
- 题目给定的数值与单位
- 决策变量定义

## 输出骨架

```markdown
# 符号说明

本文主要符号及其含义如表 X 所示。

| 符号 | 含义 | 单位 |
|---|---|---|
| $x$ | …… | …… |
| …… | …… | …… |

本文其余符号在首次出现处解释。
```

## 符号规范速查（核心）

- 变量与变动下标用斜体：x、t、T；x_i 中的 i 用斜体。
- 向量、矩阵用粗斜体：向量用黑斜体，矩阵用大写黑斜体。
- 数学常数 e、π、i 以及微分 d、增量 Δ 用正体。
- 函数名与运算符用正体：sin、cos、log、exp、max、Σ、Π。
- 单位一律正体，数值与单位之间留空格（30 min、8 h）；单位采用 SI 或法定计量单位。
- 描述性下标用正体、变量下标用斜体：T_max 中 max 用正体，x_i 中 i 用斜体。
- 同一符号全篇含义唯一；不使用程序变量名。
- 符号命名要短：变量主体用单个字母（如 T、W、C、x），必要时加简短下标；禁止用 time、duration、cost 等多字母单词作变量名。
- 下标要短：变动下标用单字母（k、r、d、i、j）斜体；描述性下标用 1~3 个字母的规范缩写（s、e、max、OT）正体。
- 同一字母体系：同类量用同一字母，如时刻用 T、时长用 ΔT、成本用 C、工时用 W、决策变量用 x；避免一个字母表示多个量。
- 三线表规范：数字不带单位，单位归并在表头栏目；量名与单位可用“符号 / 单位”形式。
- 只列主要符号，临时变量可不列；下文首次出现的符号仍要解释。

## 常见句式

- 引入：“本文主要符号及其含义如表 X 所示。”
- 表注：“本文其余符号在首次出现处解释。”

## 自检清单（强制最后一步）

1. 正斜体：变量与变动下标斜体，数学常数、函数名、单位、描述性下标正体，向量与矩阵粗斜体。
2. 单位规范：SI 或法定计量单位，数值与单位之间留空格。
3. 符号唯一：同一符号全篇无多义。
4. 无程序变量名。
5. 三线表结构：符号 / 含义 / 单位三列齐全，数字不带单位。
6. 数量适中：只列主要符号。
7. 命名规范：符号主体为单字母，下标简短；无长单词变量名；同一字母体系。
8. 无多余小括号。
9. 反 AI：无概念堆叠、无营销化措辞。
