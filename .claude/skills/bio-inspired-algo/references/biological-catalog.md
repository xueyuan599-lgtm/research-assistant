# Biological Mechanism Catalog

用于生物启发算法设计的生物机制目录。标记了每个机制是否已被算法化及开发程度。

## 已被充分开发的机制

这些生物行为已有多个成熟算法，直接做容易撞车（除非你的数学建模有本质不同）。

| 蚁群信息素 | ACO (1991) | 非常饱和 |
| 人工蜂群采蜜 | ABC (2007) | 非常饱和 |
| 灰狼社会等级 | GWO (2014) | 非常饱和 |
| 蝙蝠回声定位 | BA (2010) | 饱和 |
| 布谷鸟寄生 | CS (2009) | 饱和 |
| 萤火虫发光 | FA (2009) | 饱和 |
| 鸟群/鱼群聚集 | PSO, FSS | 饱和 |

## 未被充分开发的机制

这些生物行为**在文献中较少被算法化**，是创新潜力较高的方向。

### 微生物/细胞层面

| 机制 | 描述 | 可算法化的特点 |
|------|------|---------------|
| **黏菌智能** | 多头绒泡菌的管状网络自适应 | 没有中心控制，全局最优寻路 |
| **细菌群体感应（Quorum Sensing）** | 细菌通过密度感知协调表达 | 动态切换探索/开发模式的天然机制 |
| **基因水平转移** | 细菌间直接交换 DNA 片段 | 信息交叉的全新方式，不同于 GA 的交叉 |
| **细胞趋化性** | 细胞沿化学梯度移动 | 多层次梯度响应（初级/适应/适应后） |
| **病毒免疫逃逸** | 病毒持续变异逃避免疫 | 对抗式搜索，双群追逃 |
| **肿瘤微环境进化** | 肿瘤细胞在免疫压力下的进化 | 动态约束优化 + 多目标适应 |
| **CRISPR 适应性免疫** | 细菌记住病毒序列并精准切割 | 记忆驱动的局部搜索 + 精确修正 |

### 植物层面

| 机制 | 描述 | 可算法化的特点 |
|------|------|---------------|
| **根系趋肥/避害** | 根向营养处生长，避开毒素 | 双信号寻优（+ 吸引 / - 排斥） |
| **藤蔓攀援搜索** | 藤蔓寻找支撑物向上生长 | 螺旋 + 触须反馈的 3D 搜索 |
| **食虫植物诱捕** | 捕蝇草/猪笼草的捕食策略 | 主动诱捕 + 多级触发机制 |
| **种子弹射扩散** | 凤仙花/喷瓜的弹射传播 | 远距探索 + 近距开发的结合 |
| **菌根网络** | 真菌和植物根部的共生网络 | 分布式信息传递 + 资源再分配 |
| **气孔调节** | 植物根据环境调节气孔开闭 | 多输入动态决策阈值（能源-水分 tradeoff） |
| **种子休眠/萌发** | 种子等待合适条件才萌发 | 延迟策略 — 防早熟收敛 |

## 如何从中提炼新算法

```
1. 选一个"未被充分开发"的机制
2. 回答 Phase 1 的 checklist（>4个 Yes 可继续）
3. 阅读该领域的 3-5 篇生物学论文理解机制
4. 映射到 Phase 2 的 4 种算子模式
5. 确定你的算法与已有算法的三个本质区别
6. 实现 → 测试 → 迭代
```

## 交叉验证

如果选中的机制已有类似算法，确保你的设计至少在**两点**上不同：
1. **机制建模方式** — 不是简单套用 PSO 公式
2. **数学结构** — 引入新算子或新参数控制
3. **应用场景** — 或者算法机制相同但证明能解决某一类特定的难问题
