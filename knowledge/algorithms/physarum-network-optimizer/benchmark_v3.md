## 关键结论

1. **SHCA + CAS 显著提升局部精度**: Sphere 提升 104×，Ackley 提升 21×
2. **CG-PSR 改善 FES 利用率**: 种群从 50 逐步缩减，后期更专注开发
3. **Cauchy 变异辅助停滞恢复**: 重尾分布比高斯分布更有效逃逸局部最优
4. **CMEA 存档机制保持多样性**: 丢弃解信息回注入图结构，防止早熟
5. **Rastrigin 略差**: 需要进一步调优 p_gwo 调度或启用 GC-MMS 的多策略互补
6. **与 GWO 相比仍有差距**: 尤其是在 Sphere/Rastrigin 上，PNO 图结构探索的代价

## 参数调整指南（v3.0 新增）

| 场景 | 调整 | 原因 |
|------|------|------|
| 追求极端精度 | `use_clls=True` | 启用局部搜索，对 Sphere 类函数额外提升 |
| Rastrigin 退化 | `n_pop=100` 或 `use_cas=False` | 更多探索或回退固定 sigmoid |
| 高维 >50D | `k_neighbors=8` | 更密图连接改善信息传播 |
| 多峰函数为主 | `use_shca=False` | 固定参数可能比自适应更稳定 |
| 计算预算充足 | `use_gcmms=True` | 需配合调优，多策略可能互补 |

## 已知限制（v3.0）

1. **GC-MMS 不稳定**: 多策略池中的图差分和存档引导策略产生劣质解，默认关闭
2. **CLLS 未达预期**: 轻量二次模型需要足够邻居才能工作，30D 下效果有限
3. **Rastrigin 未突破**: 需要专门的多峰优化策略（如重启机制）
4. **GWO 单峰差距**: PNO 的图结构探索是双刃剑 — 保持多峰能力但牺牲单峰精度
