## 1. 测试目标

验证 v4.0 在实际工程优化问题上的泛化能力，重点解决 Phase 2 中发现的约束处理问题。

### 1.2 约束处理方法

| 方法 | 原理 | 预期效果 |
|------|------|---------|
| Adaptive Penalty | 惩罚因子随迭代增加 | 早期探索不可行区域，后期强制可行 |
| Feasibility Rule | Deb's 可行性规则 | 可行解优于不可行解 |
| Epsilon Constraint | ε-约束方法 | 允许一定程度的约束违反 |

## 5. 工程应用建议

### 5.1 推荐配置

```python
# 工程问题推荐配置
config = {
    'use_shca': True,
    'use_cgpsr': False,      # 禁用 CG-PSR
    'use_cas': True,
    'use_cauchy': True,
    'use_nm': True,
    'use_twophase': True,
    'phase1_ratio': 0.7,     # 70% FES 用于探索
    'restart_interval': 15,  # 每 15 代重启
    'constraint_method': 'feasibility_rule',  # 使用可行性规则
}
```

### 5.2 适用场景

| 场景 | 适用性 | 说明 |
|------|--------|------|
| 机械设计优化 | ★★★★★ | Welded Beam, Spring 等问题表现优异 |
| 结构优化 | ★★★★★ | Three-Bar Truss 几乎达到最优 |
| 压力容器设计 | ★★★★☆ | Pressure Vessel 接近最优 |
| 减速器设计 | ★★★★★ | Speed Reducer 几乎达到最优 |
| 约束密集问题 | ★★★★★ | 11 个约束的 Speed Reducer 仍能处理 |

### 5.3 局限性

1. **计算开销**：图结构构建增加约 20-30% 计算时间
2. **高维问题**：未测试 >100D 的工程问题
3. **混合变量**：未处理离散变量（如齿轮齿数）
