# Phase 5B: CEC 2017 测试集对比实验报告

> 基于 opfunu 库的 CEC 2017 单目标实参优化竞赛套件（无约束版）


## 1. 实验设置

- 测试集: CEC 2017 (opfunu 1.0.4: F1, F3-F29 共 28 个函数; 官方 F2 被排除, F30 该库未提供)
- 维度: 10D
- Max FES: 30,000（社区标准为 100,000；本实验全算法相同预算，排名公平）
- 独立运行: 10 次
- 对比算法: PNO-GWO-v4.0, GWO, PSO, DE, SHADE, CMA-ES, LSHADE-cnEPSO, jSO, EA4eig, CMODE
- 指标: 误差 (f(x) - f*)，其中 f* 为官方 bias

⚠️ **注意**: 官方 CEC 2017 约束优化版 (C01-C28) 因依赖官方 MATLAB 数据文件难以公开复现，此处使用社区标准无约束套件作为基准；约束能力由 5A 工程问题（Welded Beam、Pressure Vessel、Spring）覆盖。
