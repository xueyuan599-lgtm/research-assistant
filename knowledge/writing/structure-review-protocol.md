# 结构审稿协议（07）

> **本文件是 07 结构审稿编排口径的唯一源**：三判据的检查面、输出分级、轮次口径、委派关系、降级路径。
> `agents/journal/structure-reviewer-agent.md` 只写指针，不复制判据。
>
> 本文件管**怎么用**；**什么时候用**见 `.claude/rules/09-journal-track.md`（按需加载）。

---

## 1. 三判据

| # | 判据 | 检查面 |
|---|------|--------|
| 1 | **问题一致性** | 标题 / 摘要 / 引言 / 结果 / 讨论是否回答**同一个**研究问题 |
| 2 | **证据对应** | 每个主张是否都能对应到具体的图表、数据或文献 |
| 3 | **审稿人攻击** | 从审稿人视角攻击：问题重要性、模型设计、基准、稳健性、替代解释、结论范围 |

三判据检查的是**三个不同的复核对象**，不是同一判据的三轮迭代——轮次口径见 §3。

### 与外部技能的分工

判据与检查面在本文件定义。**攻击角度与评审深度的写法**以用户级 `academic-paper-reviewer` 的口径为准
（逻辑名引用，不复制其评审官划分与维度枚举）。

---

## 2. 输出格式

每条问题一行，五个字段缺一不可：

| 字段 | 内容 |
|------|------|
| 位置 | 文件 + 小节号或行号 |
| 类型 | 属 §1 三判据中的哪一条 |
| 影响 | 一句话说明后果 |
| **最小修改动作** | 能消除该问题的最小改动，不是重写建议 |
| 优先级 | 致命 / 重要 / 一般 |

### 分级口径

| 级别 | 判据 |
|------|------|
| **致命** | 结论超出证据、问题链断裂、主张无对应证据 |
| **重要** | 边界未界定、替代解释未讨论、图表承担多个主问题 |
| **一般** | 表述、顺序、篇幅类 |

**格式合规的分级是另一套**（见 `agents/paper-format/compliance-agent.md`）。
两者不同交付物、不同评审对象，**本文件不复制其清单，也不与其合并为一张分级表**。

## 3. 轮次口径（逐字照此执行）

> **三判据在一次调用内一次性输出全表，记为 1 轮**（`round_gate --target S7`）。
>
> 仅当某条判据产生 FAIL 需要回修时，才**对该判据单独开轮**（`--target S7-1` / `S7-2` / `S7-3`），
> 各受 `.claude/rules/06-cost-discipline.md` §二「审查轮次封顶」的 3 轮上限约束。
>
> **不新增任何计数器**——同一 `scripts/round_gate.py`、同一 `ROUND_MAX=3`，只是 `--target` 取四个不同的值。

**为什么不是「同一交付物三连轮」**：那会立刻撞上 3 轮上限。
**为什么不是「三个交付物各 3 轮」**：那会使上限形同虚设（最大 9 轮）。
三判据是**三道不同的筛子**，一次跑完；失败回修时才按筛子分轮。

推理与 `agents/mcm/critic-agent.md`「终稿自收为 1 轮」同构：全文重跑最贵，触顶后**升级用户是零额外成本的最优路径**。

### 状态记录

复用 `scripts/round_gate.py` 的既有表头与 `节点状态记录.md` 机制。
**禁止为期刊赛道另建表头或另写状态记录模板**——那会造成两份表头（`.claude/rules/01-agent-standards.md` §3 硬禁）。
该脚本的 `RECORD_HEADER` 是 `knowledge/mcm/templates/node-checklists.md` 的本地镜像，唯一源在彼处。

## 4. 外部技能缺失时的降级路径

`academic-paper` / `academic-paper-reviewer` 是用户级技能，换机或未安装时不可用。
此时**降级为「按本文件三判据执行、深度打折」**，而非整条链失效：

- 判据（是否存在缺项、是否退回）在**仓库侧**，**始终可用**
- 攻击角度的丰富度、评审视角的多样性会下降
- 降级事实记入 `07-review.md` 开头，供用户判断是否补装技能后重跑

---

## 5. 约束

- **只读**：审稿 Agent 不修改任何文件
- **一次性全表**：不分轮挤牙膏；修复后**只复核 FAIL 项**，不对已 PASS 项重复复核
- 句层自检按 `.claude/rules/02-academic-writing-standards.md` §2（唯一出处，不复述）
