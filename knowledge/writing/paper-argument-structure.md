# 论文论证结构判据（01–06）

> **本文件是 01–06 六步判据的唯一源**，同时承载跨赛道接入映射（§7）。
> `agents/journal/**` 与各步产出文件只写指针，不复制本文件的检查项与表头。
>
> **判据形态是「必须回答的问题」，不是「必须有的段落」**——候选数、段落数、顺序均可随论文与期刊调整；
> 不可调整的是**每个问题都必须有答案**。
>
> 本文件管**怎么用**；**什么时候用**见 `.claude/rules/09-journal-track.md`（按需加载）。

---

## 0. 共享口径（全文只此一处）

| 口径 | 内容 |
|------|------|
| **缺项退回** | 任一步的必答问题缺答案 → 该步产出**不得移交下一步**，退回补全后重出 |
| **不可回溯即删** | 任何无法回溯到正文或 `my-paper/` 材料的断言，一律删除，不改为模糊表述 |
| **证据设界** | 每条结论必须写清「在什么范围内成立」；超出范围的部分移入限制说明 |
| **句层自检** | 每步产出后按 `.claude/rules/02-academic-writing-standards.md` §2 执行（唯一出处，不复述） |
| **外部引用只写逻辑名** | 结构范式、写作技法、评审人格的枚举值一律不复制，按 `.claude/rules/01-agent-standards.md` §1 |

## 1. 01 标题

### 必答三问

1. 研究对象是什么？
2. 核心发现是什么？
3. 方法或范围为何值得保留？

只写「基于某方法研究某问题」= 三问全未答。

### 自检五要素

| 要素 | 检查 |
|------|------|
| 对象 | 研究谁 / 什么 |
| 核心发现 | 标题是否已透露方向（不要求给数值） |
| 方法 | 是否点明路径 |
| 范围 | 边界、情境是否清楚 |
| 证据强度 | 表述是否**超出**证据能支持的强度 |

**缺一项退回。** 第五项是删改项：「显著改善」「大幅提升」等超出证据的措辞一律改弱或删除。

### 产出

- 多个候选标题，**逐候选标注**：包含五要素中的哪些、缺失哪些
- 单列「超出证据的表述」清单

候选数可随期刊标题字数上限与领域惯例调整；**逐候选标注不可省**。

---

## 2. 02 摘要

### 必答四类信息

| 类别 | 回答 |
|------|------|
| 问题 | 研究什么问题 |
| 方法 | 怎么研究 |
| 发现 | 发现了什么 |
| 启示 | 改变了什么认识 |

**顺序可随论文调整，四类必须都在。**

### 逐句功能标注

摘要每句标注其属于上表哪一类：

- **重复**（同一类出现多次且无信息增量）→ 合并或删除
- **无法回溯**（该句内容在正文找不到对应）→ 删除

### 产出

- 逐句标注（句子 → 功能类别 → 正文位置）
- 缺失类别的显式记录

### 与外部技能的分工

双语摘要的写法与质量清单以用户级 `academic-paper` 的摘要写作口径为准（逻辑名引用）。
**本步只定义「必须回答哪四类问题」与逐句标注动作。**

---

## 3. 03 引言（问题链）

### 六段首尾相接

| # | 段落 | 必须推进到 |
|---|------|-----------|
| 1 | 现实事实 | 引出制度 / 规则问题 |
| 2 | 制度规则 | 暴露研究缺口 |
| 3 | 已有研究 | 指出未解决之处 |
| 4 | 未解决问题 | 收窄到本文要答的那一个 |
| 5 | 本文回应 | 说明如何答 |
| 6 | 学术贡献 | 说明知识与政策价值 |

### 判断标准

**每一段都必须推动研究问题前进一步**，否则是背景铺陈。

逐段标注 `推动` / `仅铺垫`。标为「仅铺垫」的段落 → 压缩或删除。

### 产出

- 六段表，每段附原文位置（`my-paper/draft.md` 的小节号或行号）
- 「仅铺垫」段落清单

### 与外部技能的分工

论证合法性（主张—证据—推理链）的构建口径以用户级 `academic-paper` 为准（逻辑名引用）。
**本步只管引言的六段推进顺序**；两者切面不同，不得互相替代。

## 4. 04 方法复现

### 七项缺一不可

对象、假设、数据、参数、基准、稳健性、限制。

### 每项必须映射到研究问题

每个假设、参数、设计动作都要能回答：「它服务于哪个研究问题？」

映射不上 → 该假设或参数是多余的，或研究问题的表述不完整。

### 四项检查

- **基准**：是否有可对比的基础方案？没有基准的结果不可解释
- **数据**：来源、口径、样本期、清洗步骤是否完整到可复现
- **复现**：数据划分、超参、评价口径、随机种子是否写明
- **稳健性**：是否检验了结论对关键假设的敏感度

### 产出

- 七项 × 研究问题的映射表
- **缺失项清单**（逐项标 `有` / `缺`）

### 与外部技能的分工

复现审计的执行深度以用户级 `academic-pipeline` 的复现审计口径为准（逻辑名引用）。
**本步定义「必须回答哪七个问题」**，审计执行不在此定义。

## 5. 05 证据映射

### 四列表（本表头为唯一源）

| 问题 | 证据 | 结论 | 边界 |
|------|------|------|------|
| 该结论回答哪个研究问题 | 图表 / 命题 / 回归表编号 | 证据支持什么 | 支持到什么范围成立 |

**列名逐字照抄本表**——`.claude/rules/01-agent-standards.md` §3 硬禁「两份表头」，其余文件只引用本表。

### 一图一问

**每个图表或命题只保留一个主问题。**

承担两个以上任务的图表 → **重新拆分**，不得在表内合并标注。

### 每行必须写清「不能支持什么」

| 项 | 内容 |
|----|------|
| 支持什么 | 该证据能得出的结论 |
| **不能支持什么** | 该证据**看似能、实际不能**得出的结论 |
| 成立范围 | 样本、时期、情境边界 |

「不能支持什么」是本节相对仓库既有规则的核心增量——既有规则只检查「图表是否被正文引用并解读」（正向），
本表补的是**反向映射**。

### 排序

核心发现 → 机制与稳健性 → 边界。

### 产出

- 四列表（问题 / 证据 / 结论 / 边界）
- 需拆分的图表清单

### 三个近名实体必须区分（硬禁两份表头）

| 实体 | 是什么 | 关系 |
|------|--------|------|
| **本表（证据映射表）** | 问题→证据→结论→边界，为结论设界 | 本文件 §5，唯一源 |
| 章节→证据的分配（外部结构设计口径的产物） | 为大纲分配证据 | **不同物**；仓库侧禁用 "Evidence Map" 指代本表 |
| 答案速查表（`agents/mcm/writer-agent.md`） | 小问→一句话答案→关键数值→位置→30 秒可定位 | **不同物**；服务评委快速定位，不得复用其表头，也不得把本表改造成它 |

## 6. 06 讨论

### 必答七问

1. 核心发现是什么
2. 改变了什么认识
3. 机制是什么
4. 是否存在替代解释
5. 结论在哪里成立
6. 政策 / 实践建议
7. 下一步研究

### 禁复述结果

**回溯结果的内容一律删除。** 讨论只写「结果意味着什么」，不写「结果是什么」。

判定：若某句可原样放进 05 的结果陈述而不损失信息，则该句属复述，删除。

### 产出

- 七问逐项作答
- 被删除的复述句清单（记明删除理由）

## 7. 跨赛道接入映射

本文件的判据**不绑定期刊投稿**。逐条适用性如下；引用方按本表取用，**不得改判据原文**。

| 判据 | 期刊赛道 | MCM 赛道 | 非赛道 T1/T2 |
|------|---------|---------|-------------|
| 01 标题五要素 | 适用 | **可用**（补 MCM 无标题自检的空白） | 适用 |
| 02 摘要四要素 | 适用 | **部分**：MCM 三类（问题 / 方法 / 结果）是刻意设计，第 4 类「启示」以可选收尾段补入，**不强制改造** | 适用 |
| 03 引言六段 | 适用 | **改写后用**：MCM 无「引言」章，「问题重述」是同位置的弱化版 | 适用 |
| 04 方法复现七项 | 适用 | **可用**（补「论文方法可复现」；现有只到「代码可复现」） | 适用 |
| 05 证据映射四列 | 适用 | **最可用**（补反向映射） | 适用 |
| 06 讨论七问 | 适用 | **不适用**：MCM 明确「结论不设独立章节」，硬塞会污染赛道 | 视体裁 |

**接入方式是单向的**：

- MCM 侧只在 `agents/mcm/writer-agent.md` 留一行指针；**本文件不写入 MCM 赛道的任何约束**，也不改其章节骨架
- 非赛道 T1/T2 经 `.claude/rules/02-academic-writing-standards.md` §2 的指针接入
- 赛道边界声明只写在 `.claude/rules/09-journal-track.md`，**单向**
