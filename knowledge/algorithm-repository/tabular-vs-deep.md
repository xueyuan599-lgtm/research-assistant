# Tabular vs Deep — 树模型与深度学习在表格数据上的选型

- **来源**: Grinsztajn, L., Oyallon, E., & Varoquaux, G. (2022). Why do tree-based models still outperform deep learning on typical tabular data? *Advances in Neural Information Processing Systems 35 (NeurIPS)*. arXiv:2207.08815.
- **方法类别**: 集成学习 / 深度学习（模型选型基准）

## 数学设定 / 核心结论

### 系统对比结论（45 个数据集）

Grinsztajn, Oyallon & Varoquaux (2022) 在 **45 个表格数据集**（规模从数百到数十万样本、含回归与分类）上系统对比 GBDT（XGBoost、LightGBM、CatBoost）与深度模型（MLP、ResNet、FT-Transformer 等）。核心发现：

1. **树模型仍在典型表格数据上占优**：在**样本量 < 约 10 万**、特征为**异质型**（数值 + 类别混合、不同尺度）时，GBDT 的预测性能系统性优于深度网络。
2. **差距来源可归因**：放大深度网络相对 GBDT 劣势的三个机制（详见下）。
3. **深度网络在「大数据 + 同质特征」下才扳回**：当样本量达数十万级、特征尺度均匀（如图像像素、标准化稠密向量）、且目标平滑时，FT-Transformer 等深度模型的差距缩小甚至反超。

### 深度网络在表格数据上失效的三机制

作者通过控制实验把"表格数据上 DNN 弱于 GBDT"归因于三个可叠加的机制：

1. **对无信息特征的敏感（Uninformative features）**：DNN 对与目标无关的冗余/噪声特征高度敏感，加入无信息特征会显著损害深层网络的性能，而树模型在一次分裂中可自然忽略无信息特征。大量"无用列"正是表格数据的常态。
2. **不平滑目标（Un-smooth targets, 阶梯/分段目标）**：当目标函数是阶梯状/接近分段的（典型表格现实）时，树模型天然匹配；DNN 依赖隐空间的平滑性假设，这在分段目标上失效。
3. **旋转不变性的矛盾（Rotationally invariant）**：DNN 对输入做线性混合（旋转）后预测不变，而表格数据的特征常是**轴对齐的稀疏结构**（一个特征一个轴的先验，如"海拔"与"温度"是两个独立语义轴）。树模型在轴对齐特征上显式建模，DNN 的旋转不变性反而稀释了这种先验。

**一句话选型结论**：样本量 < 10 万、特征异质（语义独立的数值 + 类别）、目标不平滑时 → GBDT 占优且更稳；样本量数十万级、特征同质稠密、有大量数据时 → 深度模型才值得评估。

## 关键假设（选型判断依据）

- **表格 = 轴对齐异质特征**：若特征语义独立、多尺度、含类别，倾向树；若特征是稠密同质向量，倾向深度。
- **样本规模与复杂度匹配**：深度模型需要大数据+高多样性才发挥容量；小样本下 DNN 过拟合风险高。
- **目标平滑性**：目标平滑连续（图像、音频）用 DNN；分段/阶梯目标用树。
- **可解释性与落地**：树模型天然加权分裂、易出重要性，国赛解释性要求下 GBDT 更占优。

## 适用场景

- **模型选型报告**：回答"为什么用 GBDT 而不用 DNN"的评委质疑，提供文献级依据
- **表格回归/分类基线**：国赛绝大多数问（指标体系、评价、预测）都是表格数据 → GBDT 首选，DNN 作对照
- **特征异质明显的业务表**：混合数值 + 类别 + 缺失，GBDT + MICE 组合稳健

### 不适用 / 何时转向深度

- **样本量 ≥ 数十万 / 上百万且特征同质**：可评估 FT-Transformer、TabNet 等
- **数据本身是图像 / 文本 / 音频 / 序列**：本结论不适用，直接用对应深度架构
- **需要端到端表征学习 / 嵌入**：深度模型可学习特征表示，树模型需要手造特征

## 实现要点

### 选型流程（基于证据而非直觉）

```python
# 关键：先跑 GBDT 基线，再评估深度网络是否值得，杜绝"为用而用"
# 1) 基准：GBDT（见 xgboost.md 条目），得 CV 分数
# 2) 候选深度：MLP（见 mlp-basics.md）或 FT-Transformer，严格同 CV、同早停
# 3) 对比判据：
#    - 样本量 n < 1e5 且特征异质 → 预期 GBDT 胜，深度仅作敏感性对照
#    - 深度若差 > 阈值（如 CV-RMSE 差 > 5%）→ 报告并解释为何深度不适配
#    - 若深度接近/胜出 → 报告并叠加集成（stacking）取长补短
```

要点：
- **同一 CV 协议**：两者必须在相同折、相同早停、相同评估指标下对比，否则"DNN 差"的结论无说服力。
- **用数字回应质疑**：写"GBDT 的 5 折 CV-AUC = 0.xx，优于 MLP 的 0.xx（Δ = 0.0x），与 Grinsztajn et al. 2022 在 45 个表格数据集上的结论一致"，比"树模型更适合表格数据"有力得多。
- **交叉引用**：与 `mlp-basics.md`（何时值得用 NN）、`xgboost.md`（GBDT 实现）条目配合，形成选型 → 实现 → 归因的完整链路。

## 国赛应用

### "为什么用 GBDT 不用 DNN"论证模板

> 本问为表格数据结构（数值 + 类别混合、$n$ 个样本、$p$ 个特征）。依据 Grinsztajn, Oyallon & Varoquaux (2022) 在 45 个表格数据集上的系统结论，样本量 < 10 万、特征异质、目标不平滑时，GBDT 系统性优于深度网络，且深度网络对无信息特征敏感、对旋转不变的轴对齐结构不匹配。故以 LightGBM/XGBoost 为主模型，将 MLP 作为对照：同 5 折 CV 下 GBDT 的 CV-RMSE = 0.xx，MLP = 0.yy（Δ = 0.0x），主模型选择有文献与实证双重依据。

要点：
1. **引用具体文献 + 具体数值 + 同协议对比**，构成"为什么选它"的硬证据，直接回应"为何不用神经网络"的常见评委质疑。
2. **不是贬低 DNN**：明说深度在何种条件下反超（大数据、同质特征），既科学又避免被指偏颇。
3. **DNN 作为对照而非缺席**：即使不用深度做最终模型，跑一个 MLP 对照能证明选型经过了实证检验，是全模型对比的加分项。
