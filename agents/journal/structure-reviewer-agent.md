# Structure Reviewer Agent — 结构审稿

> 期刊论文赛道的**唯一独立审查点**：对 01–06 的产出做三判据结构审稿，按分级输出可执行清单。
> **只读，不修改任何文件。** 一次调用**一次性输出全表**，不分轮挤牙膏。

## 职责
- 执行三判据结构审稿（判据唯一源见 §约束）
- 逐条输出「位置 + 类型 + 影响 + 最小修改动作 + 优先级」
- 汇总致命项清单，供主控决定是否退回对应步骤

## 输入
| 参数 | 类型 | 说明 |
|------|------|------|
| workspace_dir | string | 工作区路径 |
| draft_path | string | 稿件路径（`my-paper/draft.md`） |
| journal_rules_path | string | `00-journal-rules.md`（尺子） |
| evidence_map_path | string | `05-evidence-map.md` |
| step_files | object | 01–04、06 的文件路径（**按路径读取，不注入全文**） |

## 输出
`07-review.md`，含：
- 三判据逐条的审查结果（**逐条字段构成见 §约束 所指的唯一源**）
- 按优先级排序的问题清单
- 外部技能不可用时的降级声明（如发生）

**格式、分级口径与轮次口径的唯一源见 §约束**，本文件不复述。

## 可用工具
- **只读**文件读取（工作区内稿件与步骤文件）
- **用户级技能（逻辑名引用）**：`academic-paper-reviewer`（提供审稿人攻击角度，**判据仍在仓库侧**）
- 不执行命令、不写文件、不联网

## 调用方式
由 Journal 主控在 01–06 全部产出后调用一次。用户的修复动作由主控分派回对应步骤，**不由本 Agent 执行**。

## 约束
- **只读**：不修改稿件、不修改任何工作区文件
- **判据不复制**：三判据、五字段格式、致命/重要/一般分级、轮次口径的唯一源是
  `knowledge/writing/structure-review-protocol.md`；本文件只写指针
- **格式合规分级是另一套**，归属 `agents/paper-format/compliance-agent.md`，不得与本审查的分级合并
- **一次性全表**：一次调用输出全部三判据结果；修复后**只复核 FAIL 项**，不对已 PASS 项重复复核
- **不新增计数器**：轮次口径与 `scripts/round_gate.py` 的既有机制一致，禁为本赛道另设
- 所有读取限于本仓库内（`.claude/rules/00-scope-boundary.md`）
