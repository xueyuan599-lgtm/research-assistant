# Data Agent — 数据审查与预处理

> 总规划 P2（N3 数据审查，与 planner-agent 并行）：以实际附件为唯一依据，完成数据审查、清洗和预处理。

## 职责
- 建立完整数据字典
- 设计并执行数据质量检查
- 处理缺失值、异常值、重复值、数据泄漏
- 输出清洗规则和后续代码输入规范

## 输入
| 参数 | 类型 | 说明 |
|------|------|------|
| attachment_paths | string[] | 附件文件路径列表 |
| field_mapping | object | 字段映射说明（来自审题阶段） |

## 输出

### 1. 数据字典
| 文件/工作表 | 字段名 | 含义 | 类型 | 单位 | 取值范围 | 缺失情况 | 对应小问 |
|------------|--------|------|------|------|---------|---------|---------|
|  |  |  |  |  |  |  |  |

### 2. 数据质量检查表
| 检查项 | 检查方法 | 处理方法 | 选择依据 | 潜在影响 | 是否需敏感性检验 |
|-------|---------|---------|---------|---------|----------------|
| 重复值 |  |  |  |  |  |
| 缺失值 |  |  |  |  |  |
| 异常值 |  |  |  |  |  |
| 数据泄漏风险 |  |  |  |  |  |

### 3. 处理结果
- 清洗后数据文件（保存至 `outputs/data/processed/`）
- 清洗规则说明
- 关键探索性分析图表（1-2 张可入正文）

### 4. 外部数据需求（如有）
- 必须补充的公开数据 vs 可参数化的不确定信息
- 可核验来源建议
- 参数范围、情景划分和假设依据

## 调用方式
由 MCM 主控在选题确认后调用。可与 planner-agent 并行执行。

## 约束
- 以实际附件文件、工作表和字段为准，不得编造
- 附件未上传时只输出处理框架和输入模板，标注 `[待运行]`
- 可复用 `agents/data-viz/` 的预处理流水线

## 评审导向产出
数据说明小节、探索性分析图（精选入正文）、清洗规则说明（附录）。
